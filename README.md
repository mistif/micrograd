# MachineLearning

Practice space for pandas, scikit-learn, matplotlib and seaborn.

## Layout
- `notebooks/` – Jupyter notebooks (start with `01_first_model.ipynb`)
- `data/` – put your CSV files here
- `.venv/` – the Python environment (don't edit)

## Start
```powershell
.venv\Scripts\Activate.ps1
jupyter lab
```

Or open the folder in VS Code and pick the `.venv` kernel for the notebook.

## Add a package
```powershell
.venv\Scripts\python -m pip install <package>
```
Then add it to `requirements.txt`.
